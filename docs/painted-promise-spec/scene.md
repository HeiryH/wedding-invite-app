# Painted Promise — continuous scene and camera contract

## Format

- Event type: `WEDDING`
- Tier: `PRO`
- Intended family: `Cinematic` (new engine family; not Stage or Classic)
- Image workflow: `three-layer-v1`
- Primary production canvas: portrait, ideally 1024 × 1792 or taller with a consistent ratio
- Mobile is the compositional authority. Desktop may crop the sides or use additional lateral room,
  but must not change the story.

## Master journey

`Ring close-up → Walimah words → full dais → groom close-up → bride close-up → full dais → floral path → programme → guest place setting → guest book → memory wall`

This is one continuous illustrated wedding venue. No section may feel like a hard cut to a different
location. Each transition follows an object that already exists in the outgoing view.

## Spatial map

The bridal dais occupies the far end of a refined reception room. The couple sits beneath one airy
layered arch with ivory drapery and asymmetrical florals. A floral installation leaves the dais and
continues down one side of the aisle. Near the aisle stands the programme display. The aisle leads to
a reception table with one prepared guest place. The same table continues into a guest-book station.
A ribbon from the book rises toward a floral memory wall positioned nearer the venue exit.

The visual path is physically plausible:

1. intimate hands in the foreground;
2. pull back into the reception room and dais;
3. move around the seated couple;
4. return wide and follow the floral edge off the dais;
5. travel down the aisle to the programme;
6. approach the guest's place setting;
7. glide along the table to the guest book;
8. follow its ribbon upward to the memory wall.

## Camera grammar

- Camera motion must be slow, deliberate, and scroll-controlled on X, Y and apparent Z.
- Close-ups are genuine reframings of the same world, not unrelated enlarged illustrations.
- Wide views contain enough real detail to justify later close-ups.
- Foreground objects may pass across the frame to sell depth, but never cover live content for long.
- Every close-up has a defined return path to a stable wide or medium composition.
- Reduced-motion mode must replace travel with short crossfades between the same camera targets.

## Shared depth planes

1. **Far environment:** powder-blue wall/sky-like painted backdrop, distant architecture and light.
2. **Dais architecture:** arch, drapery, platform, fixed floral masses and ambient lanterns.
3. **Subjects and functional scenery:** bride, groom, chairs, programme board, table and memory wall.
4. **Near props:** floral branches, ribbon, stationery, lanterns and frame clusters that create
   parallax and transitions.
5. **Live content:** names, Walimah paragraph, couple details, programme, RSVP, wishes and photos.

Do not bake live content into any production plate.

## Transition anchors

- **Welcome → Walimah:** a painted floral edge and blue atmosphere survive the pullback from hands.
- **Dais → Itinerary:** the dais floral garland physically continues toward the aisle/programme.
- **Itinerary → RSVP:** the aisle and its edge lighting lead toward the reception table.
- **RSVP → Wishes:** the camera travels laterally along the same table surface and linen.
- **Wishes → Photobooth:** the guest-book ribbon rises into the memory-wall ribbon system.

## Three-layer production contract

For every section deliver:

1. `full-design.png` — complete art-directed composition and visual authority;
2. `background.png` — same environment and camera, with live text/UI and all declared movable props
   removed and hidden areas painted in;
3. `props-atlas.png` — complete, unobscured, freely packed versions of every declared movable prop.

The atlas is an inventory, not a coordinate map. Preserve facing and lighting from the full design,
but arrange objects for clean extraction.

The Walimah section additionally requires subject-detail plates because a wide dais image may not
contain enough resolution for convincing groom and bride close-ups.

## Acceptance criteria

- All six full designs unmistakably occupy the same venue and time progression.
- Transition anchors match between neighbouring sections.
- Bride/groom design, clothing, florals, furniture and lighting remain consistent.
- Every animated or adjustable object exists independently in an atlas.
- No production background contains people, movable props, text or UI assigned to another layer.
- No sacred text is used as decorative filler.
